# GitHub 复现包整理报告

## 原投稿复现包为何不足

原有 `Source_Data_and_Reproducibility.zip` 主要能支持按已发表结果表重画图片，但不足以独立重算主要统计结果：缺少统一统计入口、两套分析就绪属水平计数矩阵、患者映射、环境依赖和自动结果比对工具。

## 本次补齐内容

- 纳入 PRJNA893348 与 PRJNA428535 的分析就绪属水平计数矩阵；
- 纳入患者/样本/Run 映射、盲态 QC、排除记录和队列流程；
- 将正式主分析、敏感性分析、Firth 模型和配对分析改为仓库相对路径；
- 纳入宿主模块分数、结果、基因映射与覆盖表；
- 纳入冻结方案、签名锁、变量字典、软件记录和偏离说明；
- 纳入六张最终 PDF 图、最终结果表和逐图 source data；
- 新增 `run_all.py`、自动数值核验器、仓库结构测试、环境文件、许可证、引用文件、数据字典、来源说明和校验和；
- 清除机器绝对路径、凭据风险和内部流程性标记。

## 当前可达到的复现级别

仓库可直接完成“分析就绪数据 → 主要统计结果/敏感性结果 → 数值核验”，并可在具备 R 图形依赖时完成“冻结结果表 → 六张主图”。主结果采用固定随机种子 20260929 和 10,000 次置换/Bootstrap。

## 仍需从公共数据库获取的内容

原始 FASTQ、DADA2 RDS、RDP18 数据库、完整宿主表达矩阵及大型临时文件不适合上传 GitHub。若需从原始读段完全重建，应按 `docs/ACCESSIONS.md` 下载，并使用 `scripts/raw_preprocessing/`；这不影响仓库对论文中心统计结果的直接复算。

## 发布建议

GitHub 建议建立版本标签（如 `v1.0.0`），随后将该 release 归档至 Zenodo 获取 DOI。投稿时的数据/代码可用性声明应同时列出 GitHub release、Zenodo DOI（生成后填写）和所有公共 accession。
